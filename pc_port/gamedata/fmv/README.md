# FMV files

## PS1_INTRO.AVI

Original PlayStation 1 boot splash (PS1 logo + jingle). Plays automatically
at game startup, before the warning screen and Konami/KCET logos.

- Format: AVI (Motion JPEG, PCM s16le mono 22050Hz)
- Resolution: 640×480, 30 fps
- Duration: ~15.4 sec

Remove or rename this file to skip the PS1 intro.
